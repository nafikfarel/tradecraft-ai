# Contributing to TradeCraft AI Pro 🚀

Thank you for your interest in contributing to **TradeCraft AI Pro**! We welcome quantitative traders, algorithm developers, and UI engineers to help build the ultimate open-source financial terminal.

## 🌟 How to Contribute

- **Technical Indicators**: Add new indicators (Supertrend, Ichimoku Cloud, Stochastic RSI).
- **Exchange Connectors**: Add new exchange connectors (Bybit, Coinbase, Alpaca, MetaTrader Webhooks).
- **AI Models**: Expand prompt engineering for macroeconomic news analysis.
- **UI Components**: Enhance chart drawing tools & orderbook visualizations.

## 🛠️ Local Development Setup

```bash
git clone https://github.com/nafikfarel/tradecraft-ai.git
cd tradecraft-ai
npm install
cp .env.example .env
npm run dev
```

Open `http://localhost:3000` to view the terminal UI.
